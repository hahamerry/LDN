# 📊 Agency Weekly Client Report Engine

> Stop spending Sunday nights writing reports. Turn 5 hours per client into 5 minutes.

An AI skill that transforms raw marketing data from GA, Meta Ads, Google Ads, and CRM exports into polished, client-ready weekly reports with AI-driven insights — not just numbers.

## 🎯 What It Does

1. Pulls data from multiple sources (CSV exports from GA, Meta, Google Ads, CRM)
2. Calculates week-over-week changes automatically
3. Generates AI-driven insights with specific, actionable recommendations
4. Outputs a formatted, branded report — directly deliverable to clients

## 📦 Install

Copy `SKILL.md` to your Claude/Codex/ChatGPT skills directory.

## ⚡ Quick Start

Just say:
> "Generate this week's client report for Acme Corp — here's the data"
